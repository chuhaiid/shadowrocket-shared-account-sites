## 为什么小火箭共享账号经常用不了

这不是某一个站的问题,是共享这种方式本身带来的:

- **很多人同时在用同一个账号。** 只要有人反复输错密码或答错密保,账号就会被自动锁定,提示「已被锁定」「因安全原因被停用」,要重设密码才能恢复 [6]。密码不在你手里,只能换号。
- **密码被换掉。** 有的是站长定时改密码,有的是别的使用者改的。你看到的密码可能几分钟前就失效了。
- **要求验证。** 登录时要验证码、要回答密保、要绑手机号,这些你都过不去。
- **以后更新不了。** Apple 写明:不能更新用另一个 Apple 账户购买的内容 [3]。用共享账号下载的小火箭,以后每次更新都得再登一次当初那个共享账号——而那个账号很可能已经换了密码或被锁了。很多人第一次下载成功,几个月后卡在更新上。

所以共享账号适合「临时装一次、试试看」,不适合长期用。

## 用共享账号之前要知道的事

### 1. 只登 App Store,不登「设置」顶部

App Store 用的账号可以和手机本身登录的 Apple 账户不是同一个 [1]。要避免的是在「设置」最顶部用共享账号登录整台手机:那一层管着 iCloud 和「查找」。按 Apple 的说明,打开「查找」时激活锁会自动打开,之后任何人都必须输入这个 Apple 账户的密码,才能关闭「查找」、抹掉设备或重新激活设备 [2]。共享账号的密码不归你管,在这一层登录就是把手机和一个你控制不了的账户绑在一起。

### 2. 不付款、不充值、不改任何资料

首次登录 App Store 可能提示添加付款信息 [3]。看到这一步就退出换号,不要填自己的银行卡。不要改密码、密保和邮箱——改了,后面的人就都用不了了。

### 3. 不开双重认证,不填自己的手机号

双重认证的验证码会发到这个账户的受信任设备或受信任电话号码上 [4]。在共享账号上填自己的手机号,等于把号码挂到一个陌生账户上。

### 4. 有人找你要验证码,或要你去「设置」里登录,按骗局处理

Apple 明确提醒:绝不要把 Apple 账户密码或验证码告诉任何人 [5]。「付费解锁」「加好友发密码」「远程帮你登录」都不要理。

### 5. 提示锁定、停用,直接换号

看到这类提示表示账户已被自动锁定 [6]。在同一个账号上反复试只会更糟,换一个账号。

### 6. 搜不到小火箭,先看登录的是哪个地区

App 的提供情况因国家或地区而不同 [7]。登录的共享账号不是美区(或别的有上架的地区),商店里就搜不到 Shadowrocket。
